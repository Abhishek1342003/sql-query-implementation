# CodeJudge SQL Query Implementation & Verification

## Objective

This project contains SQL query implementation and verification for the CodeJudge relational database system.

The project demonstrates:

- Basic retrieval queries
- Filtering operations
- JOIN queries
- Aggregation and HAVING clauses
- Subqueries and set logic
- Output verification
- SQL reasoning explanations
